# GitHub integration

RailDock includes GitHub App manifest/setup callbacks, installation handling, repository discovery, and webhook endpoints. Organization Git-source resources expose repositories, branches, and directories to the control plane.

## Recommended setup

1. Configure the RailDock GitHub App settings.
2. Test the GitHub App configuration from administration settings.
3. Install the app for the repositories RailDock needs.
4. Add the resulting Git source to the organization.
5. Select repositories from that source when configuring services.

## Webhooks

RailDock has deployment webhook endpoints, including service-specific webhook deployment. Keep webhook secrets and GitHub App credentials in the control-plane secret store, not in repository manifests.
