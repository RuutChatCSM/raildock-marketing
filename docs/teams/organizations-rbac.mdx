# Organizations and access

Organizations group shared operational resources. The current API includes organization projects, Git sources, members, invitations, deploy keys, servers/bootstrap information, backup destinations, and data-safety settings.

## Members and invitations

Use membership and invitation flows to grant human access instead of sharing one administrator credential. Keep roles aligned with the work people need to perform.

## Deploy keys

Use deploy keys for automation that should not depend on an interactive user's session. Rotate keys and remove them when the corresponding CI/CD integration or environment is retired.

## Activity

Review organization and project activity as part of incident diagnosis and change review. Operational history is most useful when shared accounts are avoided.
